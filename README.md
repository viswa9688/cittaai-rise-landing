# CittaAI RISE — Landing Page

Marketing site for **CittaAI RISE** (Rapid Idea-to-Agent Sprint Experience) — Idea2Agent Edition.

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Config

Set the registration portal URL in `src/content.ts`:

```ts
export const REGISTER_URL = '#register'
```
